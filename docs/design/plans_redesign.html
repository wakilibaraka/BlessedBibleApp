Flow · from the Study page to the Bible text

Today it takes up to 5 taps to read the first day of a new plan: Study → Plans → Plan (begin) → Start → Day row → Reader. Proposed: 2 taps when a plan is already active (the Read button on the Study widget or the Plans hero opens the reader directly), and 3 taps for a new plan (Plans → plan → “Start & read day 1”).

1 · Study widget→ 2 · Plans page→ 3 · Plan page (merged)→ 4 · Reader Shortcut: the Read button on 1 or 2 jumps straight to 4.

3 · Plan page (merges “Begin plan” + plan detail)

One screen for both states. The separate begin screen goes away: the start date becomes an inline row, and the readings list shows straight away, so people can see what they're signing up for. The Scheduled / Flexible toggle and its explanation move into the ⋯ menu (Scheduled stays the default), which saves ~200dp. Rows are one line high with a cut-off preview, so ~8 days fit on screen instead of 5.
