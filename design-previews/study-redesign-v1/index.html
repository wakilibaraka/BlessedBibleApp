What was wrong → what changed

  • Two plan systems. Legacy dynamicReadingPlanProvider vs readingPlanProvider(family) shared nothing. → One model (see plan-detail logic panel).
  • Progress lied. Day-count treated 10-chapter Horner days equal to 1-chapter Gospel days; re-activate wiped progress; paced IDs collided (custom_paced_30). → Words-based % + UUIDs + non-destructive resume.
  • Dates drifted. Start date dropped on Begin; Mon showed as Sun; rest-day mapping used wrong weekday base; month math approximated (26/30) instead of logical days. → App-weekday conversion + logical-day calendar + rebase.
  • Streak measured opens, not reading. Rest days broke streaks; “I reflected” faked completion. → Reading-based streak, rest neutral, completedAt timestamps.
  • Reminders collided. All plans shared IDs 100–107 (last plan won), weekly loop off-by-one, orphan notifications after delete. → Per-plan IDs, plan title in body, cancel on lifecycle.
  • Theming leaked. StudyReader hard-coded goldAccent + white text + opaque scaffold (killed AnimatedBackground); date picker forced dark; orange/red destroys. → All pages use ReadingTokens + primaryColor + glass containers.
  • Discoverability. Reorder/resize behind long-press, Manage behind long-press, no Jump-to-Today, no bulk catch-up. → Visible •••, Edit mode button, Jump to Today, multi-select.
